## 🖼️ How to Add the Couple's Photo

1. Take the photo of the bride and groom together
2. Rename it to:  **couple.jpg**
3. Copy it into the **assets/** folder
4. Open `index.html` in your browser — the photo will appear automatically!

**Best photo size:** Landscape orientation (wider than tall), e.g. 1200×900 px or similar.
Any JPG, PNG, or WEBP works — just rename it to `couple.jpg`.

If you want to use a PNG or WEBP instead:
- Open `index.html` in a text editor
- Find the line:  `src="assets/couple.jpg"`
- Change it to:   `src="assets/couple.png"` (or `.webp`)

## 🌐 How to Open the Website

**Method 1 — Double click:**
Just double-click `index.html` — it opens in your browser directly.

**Method 2 — Drag & drop:**
Drag `index.html` into any browser window (Chrome, Edge, Firefox, Safari).

No internet server needed! It works fully offline (except Google Maps link & Google Fonts on first load).

## 📱 QR Code Generation

Once you're happy with the website:

1. Upload the folder to a free host:
   - **Netlify Drop** → https://app.netlify.com/drop  (drag & drop the whole folder)
   - **Tiiny.host** → https://tiiny.host  (free, instant hosting)

2. You'll get a URL like `https://your-site.netlify.app`

3. Generate QR code at:
   - https://www.qr-code-generator.com
   - https://qrcode.me

4. Print the QR on your wedding invitation cards!
